# Requirements

## v1 Requirements

### Contacts

- [ ] **CONT-01**: User can add a new contact (name, role, company, notes)
- [ ] **CONT-02**: User can edit an existing contact's details
- [ ] **CONT-03**: User can delete a contact

### Categorization

- [ ] **CAT-01**: User can tag a contact with an expertise level (beginner / intermediate / expert)
- [ ] **CAT-02**: Contact detail view shows an approach mode indicator derived from expertise level (peer mode for expert, mentorship mode for beginner/intermediate)

### Value Tracking

- [ ] **VAL-01**: User can log a favor or help given to or received from a contact (description, direction, date)
- [ ] **VAL-02**: User can log a project or deal done with a contact (title, description, date)
- [ ] **VAL-03**: Contact detail view shows a value balance summary (total given vs. received across favors and projects)

### Interactions

- [ ] **INT-01**: User can add a pinned note to a contact (key fact that always appears on the contact page)
- [ ] **INT-02**: User can remove a pinned note from a contact

### Follow-up

- [ ] **FLW-01**: User can set a follow-up interval for a contact (e.g. every 30 days)
- [ ] **FLW-02**: Contact list highlights contacts that are overdue for follow-up (interval has passed since last interaction logged)

---

## v2 Requirements (Deferred)

- Search and filter contacts by name, tag, or category
- Import contacts from CSV
- Relationship depth tag (cold / warm / deep)
- Custom free-form tags
- Log conversations and meetings with full notes
- Full interaction history timeline per contact
- Context view before outreach (summary panel before initiating contact)
- Smart suggestions — who to reach out to next, ranked by overdue + value exchanged
- Dashboard / overview of entire network health

---

## Out of Scope

- **Authentication / login** — no-auth, single-user app in v1
- **Mobile app** — web only in v1
- **Email or calendar integrations** — manual logging only in v1
- **AI-generated message drafts** — suggestions are about who to contact, not what to say
- **Team / multi-user sharing** — solo use only in v1
