# Milestone v1.0 — Networking App

## Summary

v1.0 of the local-first personal-CRM workshop demo. 4 phases, 62 atomic commits across feature work (15 Phase-2 + 17 Phase-3 + 16 Phase-4 plus docs commits), 40 v1 requirements implemented, 28/28 unit tests green, build green, README rewritten, Playwright smoke shipped.

## Phases shipped

| # | Phase | Commits | Tests added | Highlights |
|---|-------|---------|-------------|------------|
| 1 | Foundation & Static-Export Spine | (Phase 1 baseline) | 4 | Next.js 16 + Tailwind v4 + shadcn shell, Dexie v1 schema (all eventual fields pre-declared), dynamic `[id]` route under `output: "export"`, GH Pages workflow, `100dvh` shell |
| 2 | People | 15 | 10 | Full CRUD, Add Person Sheet (mobile FAB + desktop button), `TagChipInput` with autocomplete and lowercase normalization, `ClosenessChip` segmented control with instant save, cascade-delete confirm |
| 3 | Events & Linking | 17 | 6 | Events CRUD parallel to People, `StatusChip`, `AttendeesPicker` (shadcn Command multi-select), bi-directional linking (`addAttendee`/`removeAttendee` dual-writes), EVT-05 rhythmic "Add another person" loop, EVT-07 smart event-met default (`useMostRecentEvent`), route-aware FAB/TopBar |
| 4 | Search, Seed, Polish & Ship | 16 | 8 | TopBar `SearchInput` (mobile expandable + desktop persistent) → Popover with `SearchFilters`; JSON export/import via header `DropdownMenu` (lazy-loaded `dexie-export-import` for SSR safety); 8-person + 4-event seed dataset with idempotent loader + first-run prompt on Home; README rewrite; Playwright smoke E2E |
