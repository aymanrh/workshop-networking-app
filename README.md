# Networking App — Workshop Starter

Start here. Run `/gsd-new-project` in Claude Code to begin.

## Workshop checkpoints

This repo has four progression branches you can jump to at any time:

- **`00-empty`** — you are here. Empty repo, just this README.
- **`01-planning`** — after `/gsd-new-project`: PROJECT, ROADMAP, REQUIREMENTS, research/.
- **`02-discussion`** — phase context + decisions captured (`/gsd-discuss-phase`, `/gsd-plan-phase`).
- **`03-milestone`** — running app + tests + ship config (`/gsd-execute-phase` done).

If you fall behind during the workshop, `git checkout <branch>` to catch up.
